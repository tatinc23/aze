Compile and synthesize the notes to find recurring bottlenecks, then build and sell fixes for them. This is a later feature and is not built.

## Parked: selling the compiled dataset

Removed from the README on 2026-10-20. The original text:

> **A data business.** Filing and checking are free, because that's how the dataset grows. The product is the compiled, privacy-gated dataset:
> - AI labs buy the slice about where their models and agents break in the wild.
> - Tool and API vendors buy the slice about their own surfaces.

Ken's objection (2026-10-20): no one is likely to buy it, because labs can add this as a default to their own models and compile it themselves.
